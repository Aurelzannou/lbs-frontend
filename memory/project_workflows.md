Le projet LBS Education vise à numériser une école privée (primaire + collège enseignement général).
La roadmap complète est documentée dans WORKFLOWS.md à la racine du projet frontend.

**Phases prévues :**
- Phase 1 (critique) : Inscription complète + Paiements/Quittances + Dossier élève
- Phase 2 (haute) : Notes + Bulletins + Emploi du temps
- Phase 3 (moyenne) : Absences + Discipline + Dashboard stats
- Phase 4 (complément) : Notifications push + Archives + Rapports PDF

**Why:** Le projet numériste tous les processus d'une école privée africaine (contexte Bénin — Mobile Money, FCFA).

**How to apply:** Utiliser WORKFLOWS.md comme référence pour prioriser les prochaines fonctionnalités à développer. La Phase 1 est la prochaine priorité.
